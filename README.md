## 🚀 Como executar

**Pré-requisito:** [Python 3](https://www.python.org/downloads/) instalado. Nenhuma biblioteca externa é necessária — apenas a biblioteca padrão.

```bash
# Clonar o repositório
git clone https://github.com/ViitoDev/UFMS-Algoritmos-Programacao.git
cd UFMS-Algoritmos-Programacao

# Executar um exercício (use aspas por causa dos espaços no caminho)
python3 "Módulo 2 - Estruturas de Controle de Fluxo/Exercicio-3.py"
```

> [!NOTE]
> Os arquivos do Módulo 4 em `Exercicio-*.py` apenas **definem funções** e não produzem saída ao serem executados. Para testá-las, use o modo interativo: `python3 -i "Módulo 4 - Modularização/Exercicio-2.py"` e, em seguida, chame a função (ex.: `misterio_3(4)`).
